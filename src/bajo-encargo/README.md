Coloca aquí las fotos de las piezas bajo encargo (PNG, JPG, JPEG, WEBP o AVIF).

El carrusel las carga automáticamente. El nombre visible y el que se incluirá en
el mensaje de WhatsApp se obtiene del nombre del archivo, sin la extensión.
Por ejemplo: `Lampara_de_setas.jpg` aparecerá como «Lampara de setas».
